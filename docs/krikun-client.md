# Клиент Xray на ГУ (krikun-xray + krikun-seti)

## Компоненты

| Компонент | id | Роль |
|-----------|-----|------|
| **Демон** | `krikun-xray` | Xray, SOCKS `127.0.0.1:1080`, конфиг на ГУ |
| **ctl** | `krikun-xray-ctl` | root: запросы от приложения (импорт, старт, стоп, удаление) |
| **Приложение** | `krikun_seti` | **Krikun: сеть** — весь UI на русском |

## Экраны приложения

### Главная

- Статус (конфиг / служба / proxy)
- **Запустить обход** — Xray + `proxy` для RideTube (подсказка про Health check в RideTube)
- **Остановить обход** — стоп + снять `proxy`
- **Импорт с USB**
- **Удалить конфиг с ГУ** (флешка не трогается)
- **Тест связи** — YouTube (3×ping) → Google (3×ping) → **внешний IP**; кнопка **Остановить** прерывает тест

### Импорт (обязательный выбор)

1. **Выбрать флешку** — список смонтированных `/media/<метка>`
2. **Выбрать файл** — `.json` на носителе (подсказка `KRIKUN/xray.json`)
3. **Импортировать** → сохранение в `/var/opt/krikun-xray/conf/config.json`

Авто-импорт при вставке USB **только если конфига ещё нет** (первый запуск). Иначе — только через приложение.

## Техника

- Приложение пишет JSON в `/run/krikun-xray/requests/`
- `request-processor.sh` (root) вызывает `netctl.sh`
- После импорта конфиг **только на ГУ**, флешку можно убрать

См. `apps/krikun_seti/ui_flow_ru.md`, `apps/krikun_seti/netctl_client.js`, [memory-hu.md](memory-hu.md).
