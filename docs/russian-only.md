# Правило: всё в каталоге — по-русски

## Обязательное правило

**Каждый** компонент, который попадает в `maxkrikoun-gif/mgu-krikun` (app, tool, catalog-запись, релизный `.tgz`), должен показывать **русский** интерфейс:

- пункты меню и кнопки;
- заголовки экранов и диалогов;
- описания в списке MGU Store (для нашего источника);
- сообщения об ошибках и health-check, где это UI пользователя.

**Не допускается:** класть в наш catalog «как есть» с английским меню «пока переведём потом». Сначала русификация — потом merge / релиз.

Исключение: сам **MGU Store** из `robertnisipeanu/mgu-store` — не наш репо; его язык задаётся прошивкой/настройками BMW. Всё, что тянем **из `mgu-krikun`**, — только RU.

## На машине (iDrive)

- Язык ГУ **Русский** (рекомендуется для `auto` в сборках DarkMuse).
- Для нашего контура сборки и каталога целимся в явный **`ru`**, а не «надеемся на Auto».

## Где прописывается русский

| Уровень | Что сделать |
|---------|-------------|
| **catalog.json** | у **каждой** записи блок `texts.ru` с `title` и `description` |
| **mgu-repo.json** | у apps/tools — `texts.ru`; заголовки в Store не на английском |
| **component.json** (tool) | `texts.ru`, при необходимости строки activate/deactivate по-русски |
| **app / mgu-app.json** | сборка с **`--language ru`** (или эквивалент), не сырой EN-пакет |
| **RideTube** | в **нашем** форке/патче: язык по умолчанию **Русский**, полный `ru` в UI (upstream уже имеет `ru` — фиксируем default и проверяем меню) |
| **krikun-xray** | все пользовательские строки в UI Store/tool — на русском |

### Сборка приложений (idrive7-ветка)

Брать за основу [DarkMuse1/idrive7-apps-ru](https://github.com/DarkMuse1/idrive7-apps-ru), не английский `idrive7-apps`.

В `mgu-repo.json` при repo-tree сборке:

```json
"args": ["{id}", "--language", "ru"]
```

не `en` и не «голый» upstream без `tools/build_*_ru.py`.

### RideTube

Upstream: [JustAnotherPU/ridetube](https://github.com/JustAnotherPU/ridetube) — есть перевод `ru`. В **mgu-krikun**:

1. vendor-копия или subtree;
2. дефолт языка = **ru** (настройка / патч при сборке catalog);
3. перед релизом catalog: пройти меню, Health check, ошибки — **на русском**.

### Свои tools (krikun-xray)

- `texts.ru` в manifest;
- `title` / `description` в каталоге — русские;
- логи в файл могут быть English; **то, что видит водитель — RU**.

## Чеклист перед попаданием в catalog / main

- [ ] Есть `texts.ru` (title + description) в catalog / mgu-repo
- [ ] Установка на ГУ с языком **Русский** — меню приложения без английских «хвостов»
- [ ] Store (список **нашего** источника) показывает русские названия
- [ ] Tool: системные сообщения в UI (если есть) — RU
- [ ] Документация в репо может быть на русском (как сейчас)

## CI / релиз (когда появится)

Скрипт публикации catalog **отклоняет** компонент без `texts.ru`.

Тег релиза `catalog` не выкладываем, пока чеклист не зелёный для **всех** `components`.

## Принцип одного источника

Пользователь добавляет в Store **только** `maxkrikoun-gif/mgu-krikun`. Значит, **весь** видимый набор приложений с этого источника обязан соответствовать этому правилу — не «одно RU-приложение из десяти».
