# «Krikun: сеть» — экраны (RU)

## Главная

- **Закрыть** — выход из приложения (кнопка внизу / `BTN_EXIT`)
- Статус: конфиг на ГУ / служба / proxy
- **Запустить обход**
- **Остановить обход**
- Кнопка → **Импорт**
- **Тест связи** — Google → YouTube → внешний IP выхода

## Проверка связи

1. **Запустить тест** (лучше при включённом обходе)
2. Порядок: **YouTube** (3 пакета) → **Google** (3 пакета) → **внешний IP**
3. Во время проверки — **Остановить тест** (прерывает ping / запрос IP, показывает что успело выполниться)
4. Результат:
   - **YouTube** / **Google** — ping по одному пакету с возможностью отмены между пакетами
   - **Внешний IP** — через SOCKS `127.0.0.1:1080`, если Xray активен; иначе напрямую

Ping идёт по обычной сети (ICMP не через SOCKS). IP показывает, под каким адресом виден интернет при запросе через прокси.

## Импорт

1. **Выбрать USB-носитель** (список из `/media/...`)
2. **Выбрать файл** (`.json`, по умолчанию подсветить `KRIKUN/xray.json`)
3. **Импортировать** → копия в `/var/opt/krikun-xray/conf/config.json`

## Удаление

- **Удалить конфиг с ГУ** (подтверждение «Да») — без удаления файла на флешке

Авто-импорт с USB **отключён**, если конфиг уже есть — только явный выбор в приложении.
