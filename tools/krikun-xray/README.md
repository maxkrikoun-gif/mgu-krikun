# krikun-xray

Демон Xray на ГУ: SOCKS `127.0.0.1:1080`.

- UI для водителя: приложение **`krikun_seti`** («Krikun: сеть») — [docs/krikun-client.md](../../docs/krikun-client.md).
- Импорт без SSH: USB **`KRIKUN/xray.json`** или `incoming/xray.json`.
- Сборка бинарника: `./build.sh` (Xray-core с GitHub, не в git).

Схема: [docs/xray-on-hu-design.md](../../docs/xray-on-hu-design.md).
